# SQL Subqueries, Views, and Triggers

This repository contains advanced SQL practice focused on subqueries, reusable views, and trigger-based automation.

## Project Overview
The repository is split into two parts:
1. Subquery practice using employee and department scenarios
2. View and trigger implementation using a company database

## Topics Covered
- Single-row subqueries
- Multi-row subqueries
- Correlated subqueries
- Simple views
- Complex views
- Aggregated views
- Updates through views
- BEFORE INSERT trigger
- AFTER INSERT trigger
- AFTER UPDATE trigger
- BEFORE DELETE trigger
- AFTER DELETE trigger

## Database Used
CompanyDB

## Files Included
- `01_problem_statements/`
- `02_schema_and_setup/`
- `03_completed_solutions/`

## Key Learning Outcomes
- Practiced nested SQL logic
- Learned when to use single-row vs multi-row subqueries
- Built reusable views for reporting
- Used triggers for validation, logging, and archiving
